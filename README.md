# About this project
A Discord music bot that enables YouTube and Spotify playback in voice channels, with persistent playlist and queue management.

# Features
- Play music from YouTube and Spotify directly in Discord voice channels
- Create and manage personal playlists
- Persistent queue history stored in MySQL
- Containerised deployment with Docker

# Tech Stack
- Runtime: Node.js
- Language: TypeScript
- Framework: Discord.js
- Database: MySQL
- Testing: Jest (unit and integration tests)
- CI/CD: GitHub Actions
- Containerisation: Docker, Docker Compose
